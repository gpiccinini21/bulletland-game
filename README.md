# Bulletland
Bulletland is a rogue-like / bullet hell game made in Unity that started as a degree project.
The game on it's current state uses placeholder assets and designs that are not final.
The game will be updated, adding more features and content in the future.
##
Bulletland es un juego rogue-like / bullet hell hecho en Unity que comenzó como un proyecto de título.
El juego en su estado actual utiliza recursos placeholder y diseños que no son finales.
El juego será actualizado, añadiendo más funcionalidades y contenido en el futuro.
